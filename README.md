# Tic-Tac-Toe

Простой проект игры "Крестики-нолики" на React + TypeScript + Vite.

## Описание

Это веб-приложение для игры в крестики-нолики между двумя игроками на одном устройстве. В проекте реализованы:

- игровое поле 3x3;
- проверка победителя и ничьей;
- подсветка выигрышной линии;
- подсчёт очков по партиям;
- новая партия и сброс счёта;
- адаптивный интерфейс.

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

После этого откройте локальный адрес, который покажет Vite в терминале.

## Сборка

```bash
npm run build
```

## Правила игры

Игроки по очереди ставят X и O на свободные клетки. Побеждает тот, кто первым соберёт три символа в ряд по горизонтали, вертикали или диагонали. Если все клетки заполнены, а победитель не найден — объявляется ничья.
